# 0005 — Flow

## Context

Flow is the vertical space between blocks of content, such as a heading and its paragraph, or one card and the next.

Prose and product interfaces need different densities, but contexts can nest. A fixed gap that suits one context looks wrong in another.

Vertical rhythm used to be set partly by typography and partly by hand-placed margins. We needed one way to set it, with density taken from the context and component spacing protected from outside rules.

## Decision

- **Flow sets the space between blocks. Typography never does.**
- **The context defines the value of the step.** There are four steps: `tight`, `default`, `loose` and `section`. `flow-prose`, `flow-product` and `flow-compact` each give them their own values. Product is the default.
- **Flow assigns steps based on markup, and authors can override them.** Headings, captions and block objects get a step without extra classes. An `mt-flow-{step}` or `gap-flow-{step}` class replaces the assigned step.
- **Flow spaces only the direct children of its context.**
- **A component that declares its own context or spacing is sealed.** Outer flow stops at it. To keep its density wherever it is placed, a component declares a context. It does not fix individual gaps.

## Options considered

- **One ramp of four steps, with density set by context** (chosen)
- **Margins owned by typography roles.** Not adopted. Each role then had to answer for layout as well as type, and spacing changed whenever a role was reused somewhere else.
- **Utilities named by context (`mt-flow-prose-loose`).** Withdrawn. A component using them would bring a fixed density into any context it was placed in.
- **Making author-set steps win through higher specificity.** Not adopted. Each new rule would push specificity higher. An exclusion in each rule's selector keeps every rule at the same weight.

## Consequences

- Values live only in `flow.css`. Behaviour lives only in `flow.cjs`.
- "Direct children" also covers the caption of a `figure`, the items of a top-level list, and the terms and definitions of a `dl`. `.chart` is spaced like a `figure`.
