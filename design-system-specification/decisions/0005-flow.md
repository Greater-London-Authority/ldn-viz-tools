# 0005 — Flow

## Context

Flow is the vertical space between blocks of content, such as a heading and its paragraph, or one card and the next.

Longform and product interfaces need different densities, but contexts can nest. A fixed gap that suits one context looks wrong in another.

Vertical rhythm is set partly by typography, when using the longform-typeset and partly by hand-placed margins in a product context. We needed a unified way to set it, with density taken from the context and component spacing protected from outside rules.

## Decision

- **Flow sets the space between blocks and Typography (when using the longform-typeset).**
- **There are three flow contexts** `flow-spacious`, `flow-standard` and `flow-compact`. Standard is the default.
- **The context defines the value of the step.** There are four steps: `tight`, `default`, `loose` and `section`.
- **Flow assigns steps based on markup, authors can override them using Utility classes.** When a flow context is initiated direct children in the context are spaced vertically to the default step of that context. In a `longform-typeset` context spacious flow is applied automatically because flow can be inferred from the markup; Headings, captions and block objects are assigned a step without extra classes.
  Where an over-ride is needed or a context cannot infer spacing from markdown alone a `mt-flow-{step}` or `gap-flow-{step}` class replaces the assigned step.
- **Flow spaces only the direct children of its context.**
- **A component that declares its own context or spacing is sealed.** Outer flow stops at it. To keep its density wherever it is placed, a component must declare its own context.

## Options considered

- **One ramp of four steps, with density set by context** (chosen)
- **Utilities named by context (`mt-flow-spacious-loose`).** Withdrawn. A component using them would bring a fixed density into any context it was placed in. The correct usage is (`mt-flow-loose`) within a `flow-spacious` context.
- **Making author-set steps win through higher specificity.** Not adopted. Each new rule would push specificity higher. An exclusion in each rule's selector keeps every rule at the same weight.

## Consequences

- Values live only in `flow.css`. Behaviour lives only in `flow.cjs`.
- Attention has to be paid to nested structures.
- "Direct children" also covers the caption of a `figure`, the items of a top-level list, and the terms and definitions of a `dl`. `.chart` is spaced like a `figure`.
- Use flow for vertical rhythm between siblings inside a container, set once on the parent so content can change without anyone touching spacing (as when using markdown); use spacing classes for horizontal spacing, padding, and component internals
