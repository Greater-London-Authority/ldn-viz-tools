11 · Content styles: unclassed markup

The same Markdown-like markup in each set-up. Inside a typeset it takes the content styles (sd/content.css) in longform and in formatted product. Plain .typeset-product sets type only, as a component root does. With no typeset class, or inside .not-typeset, it keeps the reset: no list markers, no link colour. In the nested panel, the plain product island takes neither longform's content styles nor its own.
